# DISCOVERY: Individual features are erodible; the supplier ESG data layer is the structural moat

## What was found

Feature-by-feature replicability analysis reveals a consistent pattern: each of the four MVP features can be replicated by well-funded incumbents within 6–36 months. Feature 1 (data orchestration) is replicable by Sweep in 18–24 months. Feature 2 (WhatsApp supplier collection) is replicable by EcoVadis in 12–18 months. Feature 4 (real-time monitoring) is replicable in 6–12 months. Only Feature 3 (evidence vault) has a 36+ month replicability window — and that window exists because the moat is methodological and legal, not technical.

**The non-obvious finding**: The moat is not any single feature. It is the **closed-loop supplier ESG data layer** that emerges when all four features are used together. The closed loop is: WhatsApp questionnaire response → evidence vault with confidence tagging → Scope 3 calculation with full lineage → framework mapping output → real-time monitoring confirms factory-level data matches supplier-reported data.

This data layer produces an 18-month historical dataset that:

1. No competitor can replicate without the same supplier relationships (WhatsApp channel) AND the same evidence methodology (Feature 3) AND the same real-time confirmation layer (Feature 4)
2. Becomes the H&M contract renewal evidence package — the switching cost is not just the software, it is rebuilding 18 months of documented Scope 3 supplier data in a new system
3. Enables benchmarking: "your suppliers are 15% less energy-efficient than the Bangladesh garment industry average" — a product feature no competitor can offer without the same data layer

## Why this matters

All prior analysis treated each feature as a standalone product capability. The strategic implication is different: **the product is not four features. The product is a supplier ESG data platform with four ways to collect data into that platform.**

## For Discussion

1. **Counterfactual**: If EcoVadis adds WhatsApp supplier collection in 2027, does the closed-loop data layer still matter? Or does the fact that EcoVadis already has 130K rated companies mean its data layer is already deeper? What would it take for EcoVadis to compete on the data layer?

2. **Scope**: The "data layer" framing suggests the platform should optimize for data accumulation speed, not feature richness. Does this mean fewer features in the MVP, with engineering effort redirected to onboarding more suppliers faster?

3. **Revenue model**: Does the data layer imply a different pricing model — not per-feature, not per-supplier, but per-data-point-documented? What is the unit economics of Scope 3 data point collection?
